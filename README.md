# Embodied_RPACS 主工程

ACG525 / GW5A-LV25UG324C2/I1，50 MHz，Gowin 1.9.12。主工程、构建与仿真不依赖 `tests/`。

## 本次交付

2026-10-29 完成资源优化轮：主菜单裁剪至 4 项（移除 MOTOR TEST 及 0x20-0x27 调试动作）、
ASR 发送 FIFO 缩至 16 项、姿态/速度十进制转换器各共享一份（新增 result_valid 握手与
冷却拍，消除通道标签错位）、OLED 字体改为 768×8 pROM（BSRAM 9/56）、IMU 融合余数改为

Setup/Hold 违例 0（优化前 Logic 20334/89%，Fmax 53.5 MHz），BSRAM 8→9，DSP 8.5 持平。
主工程位流：`impl/pnr/Embodied_RPACS.fs`。
配套语音固件：`asrpro/release/yaoyao_asrpro_2m_20261025_obstacle/fw.bin`（本轮未改动）。
新位流已 SRAM 烧写上板验证：USB 串口每秒心跳 D 0000000000000060
（ToF 三路有效、IMU 就绪、无故障、无运动），45 秒无任何错误事件行。

## 菜单与按键

K1 下一项，K2 选择。主菜单保留 DISPLAY、MANUAL、SETTINGS、OBSTACLE AVOID；
MOTOR TEST 及其 8 个固定轮速调试动作（命令 0x20-0x27）已从菜单、页面、调度和运动链路中移除。
手动页仍执行前后 20cm、左右 90°；SETTINGS 仍含语音开关与三档速度。

语音默认关闭；到 SETTINGS → VOICE ENABLE，用 K1 选择 ON、K2 确认。
进入避障面板不运动；K2 先播报“开启避障模式”，正常播完才前进。运行中 K2 暂停，暂停后 K2 恢复。
语音关闭时显示 ENABLE VOICE FIRST 并禁止避障启动。
面板显示状态、档位、三路距离。面板距离为四位十六进制 mm（07D0=2000mm），不可用显示----；
DISPLAY→TOF DISTANCE 诊断页保留五位十进制 mm 显示。

K0 始终立即关断驱动。避障期间 K0 退出模式并返回主菜单，松开不恢复。
其他页面 K0 沿用返回/停车；主菜单 K0 复位、清故障并重新校准 IMU。

## 避障与语音

唤醒词“幺幺耍起”保持不变；“避障模式”成功后 OLED 自动跳转面板。
自主绕行完成后继续巡航，可处理后续障碍。无路可绕时暂停等待重新启动。
“停车/停止/停止任务”暂停并保留模式；“前进”在此模式内始终表示恢复持续避障。
“左转/右转/后退”取消旧路线，停稳后执行 90°/20cm 动作，完成后原地等待。
语音定量动作执行期间拒绝其他运动口令，不排队；停止与退出仍然有效。
“退出避障模式”停车、退出并回到主菜单；故障清除前禁止启动。

自主前方障碍触发一次“遇到障碍开始绕障”；完整回线、恢复航向和最终测距检查通过后触发一次“已绕过障碍物”。
取消或失败不报完成。模式存续期间每秒续期 ASRPRO 唤醒窗口。

自主避障继承独立 09 版：600mm 减速、130mm 准备绕行、三路非 20 距离≤85mm 保护、转向侧>300mm、
两次额外 300mm 及按实际横移里程返回。保留正常通信持续 20 时复用旧距离的策略；
20 不能建立首次正常值或转向后新鲜样本。

按用户确认，语音接管动作不受 ToF 近距和转向侧距离限制；IMU、编码器、动作/停车超时和已锁存故障保护保留。
自主运行期间 ToF 故障会锁存；暂停或语音接管时不新增 ToF 锁存，已经锁存的故障仍须复位。

## 实时加减速

“加速/快一点”“减速/慢一点”切换 0.05、0.10、0.15m/s，默认中档，上下端饱和。
自主巡航与语音前后直行动作实时沿斜坡调速；不会重置目标距离、累计里程或当前动作。
近障及绕障阶段优先保持 0.05m/s；原地旋转固定 0.05m/s，档位供后续动作使用。
前距≥650mm 连续三个正常新样本后解除近障限速，恢复最新档位。
暂停时调速不启动。

## 资源优化记录（2026-10-29）

| 优化 | 内容 | 效果 |
| --- | --- | --- |
| 菜单裁剪 | 移除 MOTOR TEST 入口、页面标签与 0x20-0x27 调试动作链路 | -670 LUT |
| ASR FIFO | asr_packet_tx 队列 64→16 项（最坏单周期入队 4 项，UART 每 6 字节排空 1 项） | -550 LUT |
| 共享转换器 | 三份姿态十进制管线共享一份（result_valid 握手 + 冷却拍），左右速度 BCD 共享一份（sel_d 配对路由） | -160 LUT |
| 字体 pROM | 45 个字形 case 表改为 768×8 同步读 ROM（`src/ui/oled_font.hex`，`tools/gen_oled_font_hex.py` 生成，映射进 BSRAM pROM），字符/列计数器替代 column/6、column%6 | -120 LUT |
| IMU 余数 | 带符号除 4096 的余数恒等于低 12 位符号扩展，删除三个 32 位减法网络 | ~-100 LUT |

合计 Logic 20334→17661（89%→77%），为后续功能合并预留约 2700 LUT。
工具 `tools/netlist_resource_report.py` 可从 Gowin 网表输出逐模块原语统计，用于回归资源。

## 接口与构建

ASRPRO D17/RX、D18/TX，115200/8N1；USB U8/RX、V8/TX。管脚保持既有接线，见 PIN_ASSIGNMENT.md。
协议与 ASRPRO 资源生成说明见 `asrpro/README.md`。USB 仅输出事件诊断，不需要控制心跳。

```powershell
& 'D:/Gowin/Gowin_V1.9.12_x64/IDE/bin/gw_sh.exe' build.tcl
& 'D:/Gowin/Gowin_V1.9.12_x64/IDE/bin/gw_sh.exe' verify_project.tcl
./tools/check_system_reports.ps1
./tools/run_system_sim.ps1
./tools/export_main.ps1
```

导出目录默认 `release/`，不含历史独立测试目录。
数字仿真验证控制逻辑；实际转角、距离、制动余量、光学可靠性和语音识别效果由上板测试确认。
