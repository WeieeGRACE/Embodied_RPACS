# PWM 与启动斜坡模块（2.3）

## 模块职责

`../src/pwm_and_startup_ramp.v` 是可综合的 Verilog-2001 双路 PWM/斜坡模块。左右状态独立，共用周期计数器。文件中的 `pwm_startup_ramp_channel` 是内部实现辅助模块。

不提供方向引脚、STBY、换向死区和故障锁存；这些分别由 2.2 TB6612 驱动接口和 2.9 安全保护与故障仲裁模块实现。Gowin 工程保留原有 RTL 文件引用，testbench 不参与综合。

## 接口与配置

| 信号 | 位宽 | 含义 |
| --- | --- | --- |
| clk / rst_n | 1 | 系统时钟 / 低有效异步复位；复位释放由上级同步 |
| enable | 1 | 高有效；安全仲裁后的模块使能 |
| pwm_cmd_l / pwm_cmd_r | signed 16 | 左右目标，符号代表方向，绝对值代表占空比拍数 |
| pwm_limit | unsigned 16 | 最大占空比，内部钳位到 PWM 周期拍数 |
| pwm_min | unsigned 16 | 非零目标的最小有效幅值，内部钳位到有效上限 |
| ramp_step | unsigned 16 | 每个 PWM 周期最大变化拍数；零按 1 处理 |
| pwm_out_l / pwm_out_r | 1 | PWM 波形，未经过驱动模块死区和安全门控 |
| pwm_actual_l / pwm_actual_r | signed 16 | 与 PWM 对应的当前有符号占空比 |

参数默认 `CLK_HZ=50000000`、`PWM_HZ=20000`，周期为 2500 拍。必须整除，周期须在 2～32767 拍；非法参数在仿真中报错停止，综合时排除参数检查代码。改变参数不会改变输入时钟，请提供匹配的真实时钟。

默认配置：625=25%，1000=40%，2500=100%。初次硬件集成建议外部配置 `pwm_limit=1000`；`pwm_min` 需按实际电机标定，未标定先设 0。

启动时间近似为 `ceil(目标幅值 / 有效步长) × 50 us`；例如目标 1000、步长 10，从使能后第一个完整周期开始，约 5 ms 达到目标。左右共享配置，但命令和斜坡状态独立。

## 行为与集成约定

1. 普通占空比只在周期边界更新，周期内改命令或配置不截断当前脉冲。PWM 为 `phase < duty`，0% 恒低、100% 恒高。
2. 非零命令先应用最小有效目标，再受最大上限限制。最小值不强迫启动瞬间跳变；零命令始终以零为目标，支持普通停止斜坡。
3. 换向先降至零，零占空比持续至少一个完整周期，再按最新目标符号启动；减速中恢复原方向会直接向新目标调整，不锁定旧命令。
4. 当前幅值超过新上限时，下一边界直接钳位。该规则优先于斜坡及换向，因此这次变化可超过步长。
5. `enable=0` 或 `rst_n=0` 组合屏蔽 PWM 和实际值。禁用必须覆盖至少一个时钟上升沿，才能清除斜坡和计数状态；重新使能从零开始。复位异步清零内部寄存器。
6. 全部命令和配置属于 clk 域，不在模块内执行跨时钟同步。异步急停须由上级安全模块产生可靠禁用信号；本模块不声明独立的板级急停时序保证。
7. 驱动模块按 actual 的符号生成方向，并结合 pwm_out 生成电机引脚。换向时 actual=0 没有方向信息，驱动模块应保留上一方向/换向检测状态，在新符号到达时执行其额外死区，不能将零值默认当成正转。安全仲裁同时禁止驱动接口与本模块。

## 自动仿真

需要 ModelSim 的 `vsim`、`vlog`、`vlib` 和 `vmap` 可执行文件可用。本机已安装 ModelSim SE-64 10.7。

PowerShell：

```powershell
Set-Location 'D:\Gowin\Project\Contest\Embodied_RPACS\Embodied_RPACS\Embodied_RPACS\sim'
vsim -c -l simulation.log -do run.do
$LASTEXITCODE
```

成功退出码为 0，失败为 1。脚本检查 testbench 的完成标志，避免将断言失败误判为通过。10 ms 仿真时间仍未完成会超时失败。当前目录必须是 sim 目录。

交互查看波形：在 ModelSim GUI 中将工作目录切到本 sim 目录，执行 `do wave.do`。该脚本重新编译、运行测试并显示控制、目标、实际占空比、PWM 和 phase。批处理已用 `log -r /*` 生成 `vsim.wlf`，可在 GUI 中打开波形数据库。

## 用例与实测结果

2026-10-12 在本机 ModelSim 实际运行：编译 Errors=0、Warnings=0；仿真退出码 0，共 17,550 项检查通过，仿真结束时间 2,300,251 ns。原始记录见 `simulation.log`。

| 实验 | 结果 |
| --- | --- |
| 默认频率、0% / 25% / 40% / 100% | 每周期 2500 拍、50,000 ns，20 kHz；高电平拍数分别为 0 / 625 / 1000 / 2500 |
| 左右通道与正负命令 | 左 625、右 -1000，独立得到 625 与 1000 拍高电平 |
| 超限、-32768、大步长 | 正负超限均限制到 2500；步长 65535 不发生加法溢出或越过目标 |
| 启动、停止与精确终点 | 步长 100：左 100→200→300→350；停止 250→150→50→0 |
| 正反换向 | 250→150→50→0→-100→-200→-250，零状态实测持续完整 2500 拍；右路相反 |
| 换向过程中目标改变 | 减速中恢复原方向后按最新目标恢复，未执行过期反向命令 |
| 最小有效目标 | 小命令、最小值 220：100→200→220；最小值超过上限时最终钳位 |
| 零上限、零目标、零步长 | 零上限关闭；零目标不被最小值抬高；零步长以 1 拍递进 |
| 换向时降低上限 | 当前 2000、步长 1、上限改为 100，下一边界立即到 100，再按步长减速 |
| 周期中更新命令及上限 | 当前脉冲仍保持原来 1000 / 625 拍高电平，下一边界才更新 |
| 高电平期间禁用及异步复位 | PWM 和 actual 立即归零，重新使能/释放复位后从 100 / -100 开始斜坡 |

以上为 RTL 功能仿真，未执行 Gowin 综合、布局布线、引脚约束或下载上板；未验证电机和供电的物理行为。
