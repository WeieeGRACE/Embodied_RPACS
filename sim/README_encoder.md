# 独立双路 AB 正交编码器

## 使用与接口

只需复制 `../src/dual_ab_quadrature_encoder.v`。文件包含顶层和内部单通道模块，不引用任何其他工程模块、IP、测速窗口或寄存器总线。RTL 为 Verilog-2001。

| 接口 | 类型 | 语义 |
| --- | --- | --- |
| clk / rst_n | 1 bit | 时钟、低有效异步复位；复位释放应由外部保证同步于 clk |
| encoder_a_l/r、encoder_b_l/r | 1 bit | 左右异步原始 AB 输入 |
| clear_fault_l/r | 1 bit | clk 域同步清除，至少覆盖一个上升沿；不用时接 0 |
| position_l/r | signed 32 | 累计位置，补码自然回绕 |
| delta_count_l/r | signed 2 | 合法跳变对应单拍 +1/-1，其余为 0 |
| direction_l/r | 1 bit | 最近有效计数为正时为 1，负时为 0；静止保持、复位为 0 |
| illegal_transition_l/r | unsigned 32 | 非法次数，达到 0xffffffff 后饱和 |
| encoder_fault_l/r | 1 bit | 首次非法跳变锁存；不会停止解码 |

参数 `FILTER_CYCLES=1`，`INVERT_L=0`，`INVERT_R=0`。滤波拍数必须 >=1，方向参数仅允许 0/1，非法参数在仿真中报错停止。输入时钟频率不参与计数算法。

正向 `{A,B}` 序列为 `00→10→11→01→00`，反向为逆序；每个合法边沿均计数，构成四倍频。方向反转参数翻转位置、增量和方向语义。保持状态不产生计数。两位同时翻转为非法：不改变位置及方向，输出零增量，增加统计并锁存故障，然后以新状态为基准恢复解码。

清除只清对应通道故障和非法次数，不清位置、方向或同步/滤波状态。同拍清除和非法跳变时新事件优先，非法次数为 1，故障为 1；如果一直保持清除，下一无非法事件的时钟会再次清零。

上电必须施加复位。复位释放后等待两级同步有效，再用第一个满足稳定门限的实际 AB 状态初始化，不把复位寄存器的 00 当成运动起点。初始化完成前的运动不保证计数，应在静止状态启动。

## 时序与滤波限制

A/B 分别经过两级同步，然后对完整 AB 状态执行连续稳定 N 拍判断，N 为 FILTER_CYCLES。同步器标记 ASYNC_REG；应在 Gowin 综合和时序报告中检查同步器实现与布局。

从原始输入首次被上升沿采样，到输出计数更新，延迟为 N+1 个完整时钟周期；异步边沿到首次采样还有不足一周期的相位延迟。输出在更新沿之后有效，下游时序逻辑在下一沿采样。

原始每个 AB 状态须覆盖至少 N 个采样沿。硬件建议每个状态保持不少于 N+1 个时钟周期并留额外裕量，滤波时间须明显小于最高轮速下相邻合法边沿间隔。50 MHz 默认仿真下每周期 20 ns；N=1 的功能路径延迟为 40～60 ns。小于 N 个连续同步采样的状态被拒绝；N=1 不进行多拍毛刺抑制。

采样带宽之外的跳变可能丢失，甚至跳过一整周期后无法被非法统计发现。RTL 仿真不验证真实亚稳态，不把断线、静止或堵转自动判为编码器故障。

## 一键本地 ModelSim 仿真

在本文件所在 sim 目录执行：

```powershell
& 'D:\app\modesilm\win64\vsim.exe' -c -l encoder_simulation.log -do run_encoder.do
$LASTEXITCODE
```

只编译编码器 RTL 与独立 testbench，使用 work_encoder 工作库。断言失败、未完成或 10 ms 超时均返回非零，成功返回 0。使用独立参考模型的相位索引运算与连续采样计数逐拍核对位置、增量、方向、非法次数和故障。

GUI 查看：切换工作目录到 sim 后执行 `do wave_encoder.do`。批处理波形保存在 encoder.wlf，GUI 脚本使用 encoder_gui.wlf。
