# 独立 TB6612 双路驱动接口

RTL：`../src/tb6612_driver_interface.v`，Verilog-2001，不引用其他工程模块。
文件内的 tb6612_driver_channel 仅为私有辅助实现，与主模块一同编译。

## 接口

| 信号 | 定义 |
| --- | --- |
| clk / rst_n | 系统时钟 / 低有效复位 |
| enable | 高有效使能 |
| emergency_stop / fault / watchdog_timeout | 任一个为 1 强制关闭所有输出 |
| pwm_signed_l/r | signed 16 位；正负决定方向，绝对值是每周期高电平拍数 |
| PWMA / AIN1 / AIN2 | 左轮 TB6612 输入 |
| PWMB / BIN1 / BIN2 | 右轮 TB6612 输入 |
| STBY | 全局待机控制，禁用和故障时为 0 |

默认 CLK_HZ=50000000、PWM_HZ=20000，周期 2500 拍、50 us。
625=25%，1000=40%，2500=100%；超出周期的幅值自动饱和，-32768 正确处理。
时钟必须与参数匹配，频率必须整除，周期范围 2～32767。
默认 DIR_DEADTIME_CYCLES=2500，即 50 us，须 >=1。

## 行为约定

- 左右命令独立，在 PWM 周期边界原子采样。普通零命令在下一边界停止；紧急停止走独立安全输入，不等周期边界。
- 正向 IN1=1/IN2=0；反向 IN1=0/IN2=1；零命令 IN1=IN2=PWM=0，为高阻停止。非零方向的 PWM 低阶段为 TB6612 的短路制动行为。
- 换向先屏蔽 PWM，再保留原方向完整等待设定死区，切换方向后再等待一拍建立时间。包括从零重新启动时的反向。死区内使用最新采样命令；不会执行过期方向。
- 首次启动同样先建立方向；因此首次脉冲可能被缩短。换向也会截断或跳过 PWM 脉冲，稳定运行后恢复标准占空比。
- 复位、禁用、急停、故障、看门狗超时异步关闭所有引脚并清空状态；释放经过两拍同步，再从零启动。短于一拍的安全脉冲在 RTL 仿真中同样会清状态。
- 模块不自行计时产生看门狗超时，也不锁存故障原因；watchdog_timeout 接受外部超时标志。不使用时必须明确接 0。
- 故障输入解除且 enable 仍为 1 时会重新启动；需要人工重新使能或故障锁存时，由调用方保持 fault 或关闭 enable。
- 本模块内部生成 PWM，不含启动斜坡、PID 或通信协议。输入命令属于 clk 域，跨域多位命令须由调用方握手。无需连接已有 PWM 模块。
- RTL 的立即关闭不代表已验证板级延迟；上板仍需复位约束、异步复位释放路径检查、安全输入脉宽验证及真实电机测试。未执行综合、布局布线或下载。

## 实际仿真

2026-10-12 使用本机 ModelSim SE-64 10.7，独立编译驱动 RTL 与 testbench；
Errors=0、Warnings=0、退出码 0，30039 项检查通过，结束时间 3000472 ns。
日志：`tb6612_simulation.log`；波形：`tb6612.wlf`。

覆盖 20 kHz 周期和 0/25/40/100% 占空比、双路独立方向、正负极值饱和、
精确 2500 拍换向死区及一拍方向建立、周期中改命令、取消换向、
急停/故障/看门狗/禁用/复位的短脉冲关闭与恢复、持续禁用。

在本 sim 目录执行：

```powershell
vsim -c -l tb6612_simulation.log -wlf tb6612.wlf -do run_tb6612.do
```

脚本检查 completed 标志，断言失败或超时返回非零。
交互波形查看：ModelSim 工作目录切到本 sim 目录，执行 `do wave_tb6612.do`。
