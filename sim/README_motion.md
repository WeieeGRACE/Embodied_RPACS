# 动作控制与模式状态机

## 职责与接线

RTL 为独立可综合 Verilog-2001；自检平台使用 SystemVerilog。无需任何其他模块即可编译运行。已存在于 Gowin 工程文件列表，不需加入仿真文件到综合工程。

默认 CLK_HZ=50000000、TICK_HZ=1000，周期必须整除；控制节拍 1 ms。rst_n 异步清零、释放由上层同步。所有控制、配置和多字段反馈必须在 clk 域一致提交；本模块不做 CDC。外部故障与禁用组合屏蔽输出，不等节拍；异步板级急停及最终 PWM/STBY 仍应接安全仲裁模块。

| 输入/输出 | 类型与含义 |
| --- | --- |
| enable / stop_request | 使能 / 普通停车请求；停车可保持高，需释放后再发动作 |
| external_fault / clear_fault | 外部严重故障 / 清锁存；仅已锁存、禁用且外部故障解除时清除 |
| cmd_valid / cmd_ready | 同拍为高接收一次；握手后发送端撤销 valid，避免回到空闲后重复提交 |
| cmd_mode [3:0] | 2 前进、3 后退、4 左转、5 右转、6 原地旋转、7 定距离 |
| cmd_end [1:0] | 0 连续、1 定时间、2 定距离、3 定角度 |
| cmd_reverse | 定距离后退 / 原地旋转顺时针；其他模式忽略 |
| cmd_speed_l/r [31:0] | 无符号非零速度幅值，最大 0x7fffffff；单位 count/测速窗口 |
| cmd_goal [31:0] | 毫秒 / 每轮编码器计数 / 毫度，有限动作范围 1..0x7fffffff |
| cmd_timeout_ms [31:0] | 接收到停稳全过程截止时间；有限动作必须非零，连续动作零表示无限 |
| cmd_speed_limit [31:0] | 非零，最大 0x7fffffff；超限命令拒绝，不悄悄钳位 |
| cmd_accel_step / cmd_decel_step [31:0] | 每毫秒目标速度幅值变化量；非零，支持 0xffffffff |
| position_l/r signed [31:0] | 自由运行模 2^32 累计编码器位置；前进正方向，动作中不可清零 |
| speed_l/r signed [31:0] | count/测速窗口；与目标同单位，默认上层窗口 10 ms |
| speed_valid_l/r | 两轮独立新样本脉冲；不能将保持的数据伪装成持续更新 |
| yaw_mdeg signed [31:0] / yaw_valid | 解缠绕累计毫度 / 新样本脉冲；逆时针为正，非更新期间数据保持 |
| target_l/r signed [31:0] | 左右轮目标，连接速度控制器；不是 PWM |
| drive_enable / controller_clear | 本模块运动许可 / 控制器清历史请求；后者在禁用、空闲、故障和等待停稳时为高 |
| mode / phase / busy | 模式、执行阶段、动作进行中；等待停稳仍 busy |
| done / aborted / rejected | 单时钟事件；done 仅正常动作停稳，aborted 为取消/禁用/故障，rejected 为当前命令未接受 |
| reason [3:0] | 最近事件原因，保持到下一事件或成功命令 |
| fault_code [7:0] | 首个故障锁存编码，清除后零 |

命令的速度、目标、加减速、超时、方向和结束条件在接收时锁存。反馈超时、静止阈值和样本数为静态参数。

## 行为约定

mode 编码：0 DISABLED、1 IDLE、2 FORWARD、3 BACKWARD、4 TURN_LEFT、5 TURN_RIGHT、6 ROTATE、7 DISTANCE_MOVE、8 BRAKE、9 FAULT。phase：0 NONE、1 ACCEL、2 RUNNING、3 DECEL、4 WAIT_STILL。

前进/后退/旋转/定距离要求两轮幅值相等。左转要求右轮更快，右转要求左轮更快，转弯均向前。定时间支持模式 2..6；定距离仅模式 7；定角度仅模式 6。连续旋转也支持方向选择。非法字段及必要反馈陈旧时不启动。

cmd_ready 仅空闲、安全且无停车请求时为高。忙时 cmd_valid 会逐拍报告 rejected，不排队也不抢占。因此发送端应先观察 ready；非法命令在一次握手中被消费，但 rejected=1。stop_request 无需握手。

每毫秒更新速度目标，最后一步精确钳到目标；启动每轮独立斜坡。距离按命令方向计算每轮相对起点净位移，反向位移不算到达；先到轮锁存完成并独立减速，另一轮继续。所有位置/角度运算模 2^32，单次真实净位移须小于 2^31；运行中重置反馈计数不受支持。

时间从接收命令后第一个完整毫秒开始累计。达到时间、双轮距离或旋转角度目标后减速；目标速度均归零后，重新累计两轮分别连续 STILL_SAMPLES=3 个有效静止样本。非零样本打断对应轮计数；同拍新运动优先阻止退出等待。默认 STILL_THRESHOLD=1。无新的样本不能推进静止判断。

普通停车不报告 done，停稳时报告 aborted。禁用/故障立即清零输出并取消动作。优先级为复位、故障、禁用、停车、完成、命令。复位不报告中止；故障/禁用对当前动作只报告一次中止。清故障必须禁用且外部故障解除，清除后仍 DISABLED；重新使能只到 IDLE。

默认反馈超时 FEEDBACK_TIMEOUT_MS=100，左右测速都必须新鲜，角度动作还要求角度新鲜；等待停稳超时 STOP_TIMEOUT_MS=1000。命令动作超时覆盖加速、运行、减速和等待停稳，所以应给停车留足时间。达到目标和动作超时同拍，超时优先。反馈更新同拍优先于陈旧判断。故障为首因锁存。

| fault_code | 原因 |
| --- | --- |
| 0 | 无故障 |
| 1 | external_fault |
| 2 | 左/右测速失效 |
| 3 | 角度动作反馈失效 |
| 4 | 动作总超时 |
| 5 | 等待停稳超时 |
| 6 | 非法内部状态 |

reason：0 无/新动作，1 正常完成，2 普通停车，3 禁用中止，4 故障中止，5 当前不可接收，6 命令非法或必要反馈陈旧。

## 运行仿真

在本 sim 目录执行：

```powershell
& 'D:\app\modesilm\win64\vsim.exe' -c -l motion_simulation.log -do run_motion.do
$LASTEXITCODE
& 'D:\app\modesilm\win64\vsim.exe' -c -l motion_invalid.log -do run_motion_invalid.do
$LASTEXITCODE
```

主实验应返回 0；非法参数实验有意触发 $fatal，必须返回 1。主脚本检查 completed 标志，断言失败或全局超时不会误报成功。工作库 work_motion 独立，run_motion_invalid.do 在主脚本编译后执行。GUI 使用 `do wave_motion.do`；亦可打开 motion_fast.wlf、motion_50mhz.wlf。波形保留目标、状态、事件、故障和位置/角度，避免记录高速时钟导致数据库膨胀。

自检包括：全部动作与正反方向、独立斜坡参考模型、固定随机种子 71429、最大无符号步长、命令锁存、忙时拒收、非法命令、时间边界、双轮先后到达、反向位移、正反位置/角度回绕、普通停车优先、有效静止样本、中途静止计数被打断、临界新运动、反馈失效、所有运行超时、故障清除限制、使能恢复、运行中异步复位及非法状态注入。每个终止路径检查通知类型；同步安全约束在节拍和事件处检查，异步门控单独检查。

## 实验边界

测试使用人工反馈刺激以隔离外部模块，不模拟电机机械系统。位置/角度达到目标后仍需减速，可能有实际越程；本模块不做制动距离预测，也不保证物理定位精度。速度正负相序、编码器标定、角度解缠绕及单位换算由上层保证；安全仲裁应最终覆盖 PI、PWM 和驱动。未运行 Gowin 综合、布局布线或上板测试。

## 本机实测记录（2026-10-12）

使用 ModelSim SE-64 10.7 实际运行最终版本，主实验退出码 0。RTL 和 testbench 编译 Errors=0、Warnings=0；两种配置各通过 4,865 项自检，总计 9,730 项。每轮正常完成事件 5 次、中止事件 47 次、拒绝事件 27 次，均检查每个动作终止通知不重复。减速阶段逐节拍对照独立减法参考结果。

| 配置 | 检查数 | 仿真结束时间 | 结果 |
| --- | --- | --- | --- |
| CLK_HZ=10000（加速，控制仍按 10 拍/ms） | 4865 | 234231 ns | PASS |
| CLK_HZ=50000000（实际 50 MHz，50000 拍/ms） | 4865 | 1098014631 ns | PASS |
| 非法 CLK_HZ=999 | 在 0 ps 触发参数检查 | 0 ps | 预期失败，退出码 1，Warnings=0 |

主结果见 motion_simulation.log，非法参数结果见 motion_invalid.log；波形分别保存在 motion_fast.wlf 和 motion_50mhz.wlf。负向实验中的 Fatal/Errors=1 是刻意验证参数拒绝，不是主实验失败。反馈超时/停车超时在回归中缩短到 8/7 ms，以覆盖故障；默认值分别为 100/1000 ms。
