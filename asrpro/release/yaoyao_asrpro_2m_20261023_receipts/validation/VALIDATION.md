## 上板验收步骤（待执行，不是通过记录）

1. 确认模块型号/容量、电气条件和 UART 线序，在天问启用播报打断，为当前词表生成模型及音频并编译固件；核对无错误后烧录。
2. 用串口助手以 115200/8N1 接收原始字节，逐条说 README 中所有主口令和同义词，逐字节比对发送帧。上电、唤醒、长时间静默均不得发送运动帧；没有反馈时不得播报已完成。
3. 等待休眠，在未说“幺幺耍起”时分别说“停止任务”“停车”“停止”，均须收到 `AA 55 01 02 03 0D`。分别在欢迎语、唤醒回应和状态播报期间说停止，检查实际识别成功及停止帧到达。
4. 在 15 秒窗口内及边界前后测试普通口令，识别成功后等待接近 15 秒再次发令，验证续期；休眠时普通运动口令不得触发。
5. 串口助手发送 README 表中每条响应/状态帧，确认实际语音正确；重复状态只播一次，切换后返回可再次播报，命令响应不去重。
6. 播报期间注入合法帧、坏校验、噪声、粘连帧、分段残帧及超过 20 ms 的半帧；确认接收持续运行、错误帧不播报且能恢复。测试突发消息及停止状态抢占。
7. 底盘按同一协议对接后，验证运行中拒绝新运动、不排队；停车同时取消自主/手动任务；档位升降饱和且不启动动作；标定并实测前后各 20 cm、原地左右各 90°，只有反馈到位且停车后才上报完成。
