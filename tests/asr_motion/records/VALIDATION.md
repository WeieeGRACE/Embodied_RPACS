## 实机依据及本次改动

用户提供的四次手转顺序为右、左、左、右，每次约 90°。停稳附近累计 Y 分别为 +88.741°、-1.597°、-90.103°、+2.357°，原始记录保存在 `manual_yaw_20261023.txt`。当前安装的原始航向右正左负，与动作状态机需要的左正右负相反。两版共用顶层默认 `YAW_SIGN` 从 1 改为 -1；距离参数、角度比例、90000 毫度目标、速度和超时不变。

联合仿真的 SPI 陀螺仪模型同步改为实测安装方向，独立物理航向仍保持左正，增加实际左／右旋转方向断言。单元测试同时验证正负符号下的跨 ±180° 解缠绕。以下三组 ASR 仿真及串口离线自检均为本次重新运行，退出码均为 0；两份保存工程分别重新综合、布局布线并生成位流。共享模块未改动，本次未重复运行原有系统回归。

## 接线调整与待上板项目

2026-10-23 交付修正版后，用户已确认 ASRPRO 独立语音控制实机功能测试通过，详见 [上板测试报告](2026-10-23_ASRPRO独立语音控制上板测试报告.md)。该结论为整体功能确认；下述精度和重复性项目仍需实测记录。

执行时核对发现 U8/V8 是板载 USB UART，故在计划中的电脑测试版之外增加 D17/D18 独立语音版，避免两个 UART TX 同驱动。GPIO 版可脱离电脑运行；D17/D18 为 FPGA 球位，用户仍需对照板级资料确认实际引出位置和 ASRPRO 的供电／3.3 V 信号。

默认 1456 counts/rev 和 66 mm 轮径未实测。IMU 航向符号已根据用户手转记录修正，独立语音控制功能已获用户确认通过；修正版实际旋转停止位置、真实轮周长、真实越程和五次重复精度仍待量化记录，反馈播报效果未提供单独测试结果。请按 README 完成四种动作各五次精度验收；目标距离误差 ≤2 cm、角度误差 ≤5°。仿真数值只代表所用模型，不作为实机精度承诺。
