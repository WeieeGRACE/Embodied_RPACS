## 3. RTL 结构（都按"传输无关"分层）

```text
uart_rx_8n1.v      8N1 接收（过采样、中点采样、帧错误）
crc16_ccitt.v      CRC-16/CCITT-FALSE（逐位展开 ~40 LUT，无查找表）
host_frame_rx.v    AA 55|TYPE|LEN|PAYLOAD|CRC|0D 解析 + 错误分类 + 字节间超时
host_cmd_decode.v  5 种下行命令 → 寄存器（ACK 状态码、限速裁剪、STOP 锁存）
host_link_watchdog.v  300 ms 心跳看门狗（上电即失联锁存，需显式 CLEAR_FAULT）
telem_builder.v    23 字节遥测快照
frame_tx_engine.v  发帧引擎（边发边算 CRC）
uart_bridge_core.v 传输无关核心 + 安全仲裁（STOP > 失联 > 上位机命令）
host_link_motion_adapter.v  链路 → 现有运动层的命令适配（模式/方向/幅值/刹车）
uart_bridge_top.v         板级顶层（纯链路）
uart_bridge_imu_top.v     板级顶层（链路 + IMU 真实姿态）
uart_bridge_lite_top.v    板级顶层（资源精简：8 位计数器 + 无 ACK）
```

**安全契约（三条，必须保留）**：
1. 链路只写"目标速度寄存器"，**从不直接写 PWM**；
2. 心跳超时/STOP → 目标速度归零且锁存，恢复需显式 `CLEAR_FAULT`；
3. 任何解析错误只丢弃，绝不把半帧写入寄存器。

## 5. 今晚修掉的三个重要缺陷（前两个是协议设计，第三个是安全实现）

1. **`SET_VEL` 缺 `seq`**：遥测里有 `cmd_seq` 却无来源。已把 SET_VEL 负载从 4 B 扩到 5 B
   （`int16 L | int16 R | uint8 seq`），FPGA 原样回显，上位机可统计丢帧。
2. **心跳超时 = 心跳周期**：v1.0 写的是"5 Hz 心跳 + 200 ms 超时"，等周期；在台架上
   5 Hz 心跳真的反复误判失联。已冻结为 **心跳 10 Hz、超时 300 ms**（5 Hz 时仍余 100 ms）。
3. **硬件急停此前只上报、不生效**（夜里做了一轮独立代码评审才发现）：`ext_fault[2]`
   只进遥测故障位，没进安全仲裁。若集成时把真实急停按钮接上，按住按钮车仍会继续走。
   已改为**锁存 + 强制目标速度 0 + 置 `stop_latched_out`**，松开不自动恢复、需 `CLEAR_FAULT`；
   `tb_core` 新增 5 项用例。同时补齐了命令长度校验（长度不符的 `CLEAR_FAULT` 不再解锁）。

这三个若不改，后面联调会被"随机失联 / 命令丢帧无法统计 / 急停不生效"折磨；
现在都写进协议 v1.1 与 `docs/PROTOCOL_v1.md` §5.1/§5.2 了。

## 6. 千兆网（v2）准备情况

协议层已与传输解耦，`transport.py` 里三种传输共用同一帧格式：

```python
UartTransport   # 现在：/dev/ttyUSB0 或 COM14，115200 8N1
UdpTransport    # 未来：一个 UDP 报文 = 一个完整帧（已本地回环验证 PASS）
FileTransport   # 离线回放：把串口助手抓的 hex 当数据流
```

UDP 自检结果（`tools/udp_loopback_test.py`）：200 报文 → 200 接收，150 合法帧 + 50 坏 CRC，
每个报文恰好一帧，与 UART 路径解析结果一致。**换以太网时帧格式/消息/CRC/安全逻辑一行不改**，
RTL 只需新增一个"字节源适配器"喂给 `host_frame_rx`。

## 11. 已知限制与注意事项

| 项 | 说明 |
| --- | --- |
| `host_frame_rx` 只保存前 8 个负载字节 | v1 命令都在 5 B 内；若将来要更长负载需扩存储（一致性测试已按 8 B 比对） |
| 流式解析器 vs 缓冲解析器的固有差异 | 噪声里出现非法 `AA 55` 且**紧贴**真帧时，RTL 无法回退重扫（已写入 conformance.py 注释） |
| 精简版无 ACK | 上位机改用遥测 `cmd_seq` 回显判断生效；若联调期需要逐命令确认，用完整版 |
| IMU 版未做更细的陀螺零偏温度补偿 | 沿用主工程已验证的 `imu_attitude_fixed` 行为 |
| 板子只用 SRAM 位流 | 掉电即恢复原固件；如需长期测试，请先确认整车固件的 Flash 备份 |
