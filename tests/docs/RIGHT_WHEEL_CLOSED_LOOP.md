> 阶段更新（2026-10-14）：用户确认单轮及双轮架空测试已完成，后续见 GROUND_TEST.md。以下保留历史步骤和证据，其中“尚待验收/不落地”描述属于当时阶段；新增固件和落地实机验收仍需单独记录，历史编码器异常报告保留。

左轮反向四次实测：TL=-10，速度逐步收敛至-10，稳定PL约-293~-301；
非法跳变、故障和饱和均为0，右路关闭。停机后有惯性滑行。
日志确认速度跟踪，机械抖动、温升和电流仍需实机观察。

## 工程与下载

打开 ../gowin/robot_right_forward_test.gprj，顶层 robot_right_forward_test_top。
下载 ../../impl/pnr/robot_right_forward_test.fs，选择 SRAM Program。
参数 TARGET=10、KP=32、KI=1、KD=0、TEST_RIGHT=1。
保留左轮正向、反向工程和下载文件；所有工程独立启用各自约束。

## 接线和操作

1. 断电，断开左电机 AO1/AO2 动力线；首次检查时右电机也断开。
2. FPGA 与 TB6612 控制接线保持原样：PWMB=T17、BIN1=T18、BIN2=H12、STBY=G13。
   左右编码器接线保持原样，右 A=GPIO2/F14、右 B=GPIO3/G14；UART TX=V8。
3. 下载后串口使用115200、8N1、无流控。确认 TL=0、TR=10，左路PWM及方向始终0。
   无电机时验证 KEY1松开关断、KEY2锁存急停（KEY0清除）、按住KEY1最多2秒停止。
4. 断电后仅将右电机接 BO1/BO2，采用原先已验证的正向接法；轮子架空、限流供电。
   保持左电机动力线断开，不交换编码器相序。
5. KEY0复位，先松开KEY1，再按住运行。到2秒自动停止后，必须松开再按才能重启。
   重复2~3次，记录完整启动、运行、停止日志及是否抖动、异响或发热。

预期：L/PL=0（左轮未被手动转动时），R增加，VR/SFR为正并接近10，PR为正，
驱动时BIN1=1、BIN2=0；IL/IR/FL/FR/FAULT均为0，SL/SR无持续饱和。
停止时EN/ST/PL/PR=0；速度和计数可因惯性短暂继续变化。
右轮需要独立验证增益，不能假定速度或PWM与左轮完全一致。
若PR为正而SFR持续为负，立即松开KEY1，断电后核对接线和方向约定。
不提高25%上限、不同时运行两轮；限时停止和PWM限幅不替代过流保护。

## 右轮正向实测与反向测试

右轮正向四次实测速度从6~7逐渐升至9~10，后段PR约290~326
（11.6%~13.0%），左路位置/速度/命令均为0，无非法跳变、故障或饱和。
输出关闭后有约几百毫秒滑行，最终静止；日志不能证明短时机械抖动或温升。
滤波值9/10的交替伴随约32拍PWM变化，符合整数计数和Kp=32的作用，
不凭100ms日志单独判定机械振荡。本次不改增益。
