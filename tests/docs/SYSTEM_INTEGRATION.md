# 底盘基础控制集成与事件日志验证（2026-10-18）

## 实现与操作

`Embodied_RPACS.gprj` 唯一顶层为 `robot_system_top`，只使用一套 CST/SDC。集成 IMU、双轮编码器/测速、独立 PI、PWM 斜坡、TB6612 与 UART 心跳看门狗，不包含 camera、DDR、HDMI。独立测试工程和原有工作区修改保留。

- 50 MHz；IMU SPI 1 MHz，约 200 Hz 六轴原子采样。每秒在完整采样事务之间读取 ID 和错误寄存器。
- KEY1 按一次双轮前进 8 秒，左右目标均为 10 counts/10ms。运行期间松键或再次按键不改变动作；结束后须释放至少 10 ms 再按。
- 保留 10 ms 测速、4 窗滤波、KP=32/KI=1/KD=0、20 kHz PWM、625/2500 上限和每 PWM 周期 1 拍斜坡。编码器相序沿用通过的例程。
- KEY2 急停，KEY0 复位。IMU 初始化及首样本完成、无故障且收到过有效心跳后才允许运动。
- UART 为 115200/8N1，主机每 100 ms 发二进制 A5。首个有效心跳后，空闲或运行期间 500 ms 未刷新均锁存停机。错误字节和错误停止位不刷新。
- IMU 初始化错误、非零错误寄存器、运行中 ID 不符、ready 丢失或 ready 期间连续 100 ms 无新样本均锁存停机。自动重试成功、恢复心跳或释放急停均不能解除停机，须 KEY0 复位。
- 任一故障关闭两路 PWM、方向脚及 STBY；日志发送不参与安全关断路径。
- 内部 `imu_sample[95:0]` 按低位到高位保存 AX/AY/AZ/GX/GY/GZ，[97:96] 为同步中断状态，[98] 为 T11 输入。已验证保留 99 位快照、六轴数据以及左右各 32 位位置和非法跳变计数。

闭环模块新增 `SYSTEM_INTEGRATION=0`、`TELEMETRY_ENABLE=1`，默认保持独立例程行为。集成模式输入 `system_ready/system_fault` 及已同步释放的复位，输出心跳、看门狗及左右编码器故障状态。IMU 新增 `HEALTH_CHECK_CYCLES=0`，独立例程默认不启用运行健康检查。

## 引脚与精简日志

电机 AIN1=M16、BIN1=N15，IMU MISO=U18、CS=T18，其余严格按 `PIN_ASSIGNMENT.md`。T11 显式为无上下拉输入，避免默认未用管脚上拉。28 个端口的最终位置、方向、电平、驱动及上下拉全部检查通过。

LED：D14 就绪、C14 运行、B9 故障、A9 表示复位后收到过有效心跳。心跳 LED 不表示当前未超时。

仅一套 UART TX；每行固定 8 字节，格式为 `S/E 源 两位十六进制码` 加 CRLF。每次上电/复位先输出 `S M 00`、`S N 00`、`S W 00`，IMU 首次成功或失败后输出一次 `S I xx`。
M/N/W 分别为电机逻辑、编码器逻辑、看门狗逻辑；00 表示初始化完成，不代表电机转动或编码器硬件自检通过。W 初始化与收到 A5 心跳分别由日志与 LED 表示。
IMU 启动失败时 xx 为当时驱动错误码，无驱动错误码时为 FF。正常运行不输出周期速度、位置、样本或心跳日志。

| 错误日志 | 含义 |
| --- | --- |
| E I 04 / 05 | 初始化 ID 检查失败 / 配置失败 |
| E I 06 / 07 | 运行中 ID 不符 / 错误寄存器非零 |
| E I 0A | 检测到非零传感器错误寄存器 |
| E I 08 / 09 | ready 丢失 / 采样超时 |
| E I FF | 其他非零驱动错误 |
| E W 01 | 看门狗超时 |
| E L 01 / E R 01 | 左 / 右编码器故障 |
| E X 01 | 急停 |

按固定来源和错误类别保留待发送位及已报告位，每类错误复位前最多发送一次。多个同时发生或发送过程中到达的事件独立保留，无大容量 FIFO。一个根因可产生多个诊断类别，例如 ID 错误后 ready 丢失。
