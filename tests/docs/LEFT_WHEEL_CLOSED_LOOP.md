## 接线

保持已验证的接线。FPGA 管脚编号是芯片球位，通过下面的板上网络名寻找插针；
不要把 U17 理解为排针第17脚。GPIO0..3 位于40-pin GPIO接口；
LCD_GPIO 网络位于原 TFT 扩展接口。本次不要插接 TFT 或摄像头模块。

| FPGA 信号 | 板上网络 | FPGA 管脚 | 接入 |
|---|---|---|---|
| encoder_a_l | GPIO0 | C17 | 左编码器 A |
| encoder_b_l | GPIO1 | C18 | 左编码器 B |
| encoder_a_r | GPIO2 | F14 | 右编码器 A |
| encoder_b_r | GPIO3 | G14 | 右编码器 B |
| PWMA | LCD_GPIO7 | U17 | TB6612 PWMA |
| AIN1 | LCD_GPIO6 | U18 | TB6612 AIN1 |
| AIN2 | LCD_GPIO11 | M14 | TB6612 AIN2 |
| PWMB | LCD_GPIO9 | T17 | TB6612 PWMB |
| BIN1 | LCD_GPIO8 | T18 | TB6612 BIN1 |
| BIN2 | LCD_GPIO23 | H12 | TB6612 BIN2 |
| STBY | LCD_GPIO22 | G13 | TB6612 STBY |
| uart_tx | 板载 UART TX | V8 | 板载串口桥，或外接 USB-TTL 的 RX |

管脚依据教程 `02_例程源码/ch27_rom_image_tft_hdmi/src/rom_image_tft_hdmi.cst`、
`ch9_uart_loopback/src/uart_loopback.cst` 及 `04_引脚功能信息` 的引脚表。
KEY0/B16 复位；KEY1/A15 使能；KEY2/C15 急停。LED0/D14 为使能逻辑，
LED1/C14 为急停输入，LED2/B9 为故障，LED3/A9 为选中通道控制器饱和；
这里描述逻辑值，LED点亮极性以板载电路为准。

TB6612 VCC 接3.3 V，VM 接适合电机的独立限流电源；FPGA、驱动和电源负极共地。
编码器供电沿用此前实测配置，A/B 接入电压必须符合3.3 V IO要求，必要时电平转换。
左电机两根动力线接 AO1/AO2；右电机动力线断开。STBY 始终由 FPGA 控制。
外接 USB-TTL 时只接 RX 和 GND，不接适配器 TX 和供电脚。

## 按键和默认控制

- 上电或 KEY0 复位后，先松开 KEY1 至少10 ms，再按住运行。
- KEY1 稳定按下10 ms后启动；松开时立即关断 PWM/STBY。
- 每次按住最长2秒，计时从运行请求开始，包含启动等待；到时停止。
  一直按住不能重启，须松开至少10 ms后重新按下。
- KEY2 按下立即关断并锁存故障，即使随即松开也不恢复。
  松开 KEY2、松开 KEY1，再按 KEY0 清除故障，然后重新操作。
- 编码器任一通道非法跳变故障也锁存停机。禁用或故障清除 PI 和斜坡状态。

默认 `TEST_RIGHT=0`，右路命令、PWM和方向输出均为0。
左目标 `TARGET=10`，单位是每10 ms的四倍频计数；KP=32、KI=1、KD=0、GAIN_SHIFT=0。
4窗移动平均在复位后以0填充尚未采到的窗口，40 ms后进入完整历史平均；
除法向0取整。速度测量在禁用时仍继续，重新启动使用当前轮速。
有符号反馈饱和到16位后进入控制器，避免截断翻转符号。
PWM固定20 kHz，每周期2500拍，命令幅值最大625（25%），每PWM周期斜坡最多变化1拍。
换向保留2500拍死区，最小占空比0。无反馈时首个PI控制量为330拍，约13.2%；随后随误差积分，受斜坡和625限幅约束。

## 串口观测

串口助手设为115200、8N1、无流控、文本显示。每100 ms发送完整快照，CRLF换行。
字段顺序：

```
L=0 R=0 TL=10 TR=0 VL=0 VR=0 SFL=0 SFR=0 PL=0 PR=0 SL=0 SR=0 EN=0 ST=0 IL=0 IR=0 FL=0 FR=0 FAULT=0 FC=0
```

| 字段 | 含义 |
|---|---|
| L/R | 左右有符号累计位置，KEY0清零；前进应增加 |
| TL/TR | 左右目标 counts/window |
| VL/VR | 最新10 ms窗口原始速度 |
| SFL/SFR | 4窗平均速度 |
| PL/PR | STBY门控后的安全PWM命令，有符号拍数，非电压或实测电流；驱动在周期边界锁存，可能比命令延后一周期 |
| SL/SR | 选中通道 PI/PID 饱和标志；未选通道显示0 |
| EN/ST | 控制使能 / 实际STBY逻辑；启动等待期间可为1/0 |
| IL/IR | 非法跳变累计次数 |
| FL/FR | 编码器锁存故障 |
| FAULT | 本地急停、编码器或安全仲裁故障的组合 |
| FC | 安全仲裁故障码，可能在立即关断后下一拍更新 |

累计L=1508、R=1516不能直接作为每圈计数，1456也只是参考；本阶段不换算RPM。

## 上板顺序与验收

1. 不接电机，先下载并用示波器验证：上电输出关闭；按住KEY1左路启动、
   右路PWMB/BIN1/BIN2一直为0；松开KEY1或按KEY2立即关闭；
   按住2秒后STBY/PWM变0，保持按住不重启。KEY0复位关闭。
   此时轮速为0，左PI命令随误差累计增加，最终受625拍上限限制，不能期待固定25%输出。
2. 断电后仅左电机接AO1/AO2，车轮架空，采用限流电源，保留实体断电开关。
   重新上电，按KEY1最多2秒观察：左前进时L增加、VL/SFL为正，IL/IR和FL/FR均为0，PR为0。
3. 若不能起转，先核对PWMA/方向/STBY、驱动供电和机械负载，再小幅增加KP重编译。
   不提高625上限，不用增加KI掩盖方向错误；负反馈或明显振荡立即松开KEY1。
   反馈接近TL后，P控制量应随误差减小；KI=0可能保留稳态误差。
4. 左轮验收后再把TEST_RIGHT设为1，右电机单独接BO1/BO2重复测试。
   当前生成文件为左轮版本；右轮参数版本须重新综合与验证。

2秒停止是限时运行，不是真实看门狗；PWM上限也不替代过流保护。
本次不进行双轮落地、在线调参或过流验收。
