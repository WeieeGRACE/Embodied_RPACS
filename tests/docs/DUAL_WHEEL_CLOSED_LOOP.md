# 双轮架空正转测试

> 阶段更新（2026-10-14）：用户确认单轮及双轮架空测试已完成，后续见 GROUND_TEST.md。以下保留历史步骤和证据，其中“尚待验收/不落地”描述属于当时阶段；新增固件和落地实机验收仍需单独记录，历史编码器异常报告保留。

左右单轮正反向日志均支持低速跟踪通过。右轮反向四次速度逐步收敛至-10，
后段PR约-290~-330，左路关闭，无非法跳变、故障或饱和。
关闭后惯性滑行几百毫秒，最终停止。机械抖动、温升、电流仍需现场观察。

## 工程

打开 ../gowin/robot_dual_forward_test.gprj，顶层 robot_dual_forward_test_top。
下载 ../../impl/pnr/robot_dual_forward_test.fs，选择SRAM Program。
两轮目标均10 counts/10ms，KP=32、KI=1、KD=0，4窗滤波。
每路PWM限幅625/2500（25%），斜坡每PWM周期最多1拍。
共用闭环模块新增TEST_BOTH参数，默认0，保留所有单轮工程行为。
两路独立PI和反馈，共用安全关断；任一编码器故障都停止两路。
KEY1按下一次触发运行，连续8秒后自动停止；运行期间松开或再次按下均忽略，动作结束后必须释放再按；KEY2急停锁存，KEY0清除。
限时停止不是看门狗，未加入硬件过流检测。

## 接线与顺序

1. 下载时电机动力线断开，先确认串口TL=10、TR=10。
   用示波器检查两路正向方向、PWM上限和KEY1/KEY2/8秒自动关断。
2. 确认此前单轮实测无明显抖动、异响或发热后，断电接回两台电机：
   左电机AO1/AO2，右电机BO1/BO2，保持各自单轮验证过的接法。
   编码器、UART和控制线不改变，不交换动力线或A/B相序。
3. 两轮都架空，使用限流电源并保留实体断电开关；本次不落地。
   KEY0复位，先松开KEY1，再短按约0.5秒确认两轮物理前进方向一致，松开检查停止。
4. 然后短按KEY1运行至8秒自动停止，重复2~3次，保存完整串口日志。
   分别测试提前松开KEY1和KEY2急停；KEY2后应持续关断，KEY0复位才能恢复。

预期L/R增加，VL/VR及SFL/SFR为正并接近10，PL/PR为正且幅值不超过625。
左右PWM不同是独立控制补偿电机差异，不要求两路完全相等。
IL/IR/FL/FR/FAULT为0（主动急停测试除外），SL/SR无持续饱和。
关闭后EN/ST/PL/PR为0，计数可随惯性继续变化；机械停止不是瞬时制动。
反馈符号相反、持续饱和、供电下降或明显抖动时立即松开KEY1。
记录电源电压/电流、两轮是否平稳、驱动和电机是否发热。
