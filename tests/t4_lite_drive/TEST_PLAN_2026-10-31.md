## 6. 补充（闭环版上电标定 + 逐条路线）

### 6.1 闭环位流标定（上电一次，自动）

```bash
python3 ~/t4_tools/closed_loop_calib.py
```
车放在前方 >=1.5 m 空旷处。脚本自动做：50/100 mm/s 直行 2 s 测速、左右转 1 s 测角速度与滑行，
输出 PASS/FAIL 并写 `calib.json`（`cmd_scale / turn_mag / turn_rate / turn_lead`），
之后 `route_run.py` / `run_segments.py` 会自动读取该标定。
若 VERDICT 为 CHECK，先看数据再决定是否换回开环位流。

### 6.2 分段编排（推荐顺序）

```bash
python3 ~/t4_tools/run_segments.py                 # 第 1-8 段，逐段提示
python3 ~/t4_tools/run_segments.py --start 5       # 从第 5 段继续
python3 ~/t4_tools/run_segments.py --only seg6_L_shape
```
结果写 `~/t4_logs/segments_YYYYmmdd_HHMMSS.json`；每段结束打印里程与航向变化。

### 6.3 逐条路线（A->B / A->C / A->D / A->E）

```bash
python3 ~/t4_tools/run_segments.py --suite routes --speed 25
```
每条都从 A 点出发（需要人工把车摆回 A）；按几何仿真这些路线**贴墙通过**
（确定性最小墙距 9-14 mm，见 `records/route_simulation.md`），务必低速 25、人手不离开 KEY2。
全部单条路线通过后，再考虑 `route_run.py route5_ABCDE_plan.json`
（10.2 m / 21 转，按当前地图在 B 点转向几乎贴墙，最后再试）。
