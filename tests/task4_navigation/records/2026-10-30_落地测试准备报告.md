# 落地测试准备报告（2026-10-30）

> 目标：把落地（地面行驶）测试要用的**程序**全部写好、仿真跑通，上板即用；同时把**速度上限做进 RTL**。

## 1. 速度限制（本次重点）

| 层 | 限制 | 位置 |
| --- | --- | --- |
| 段表 | 本段 `50 mm/s` | `nav_segment_table.v` 7'b1100000 |
| 航向修正 | 每轮 ≤ speed/3（约 ±17 mm/s） | `nav_event_segment_controller.v` |
| **顶层硬限幅（新增）** | 左右轮目标 **钳在 ±60 mm/s** | `nav_speed_limit.v` + `task4_navigation_board_top.v` |
| PID 输出 | 占空比 ≤25% | `PWM_LIMIT=CLK_HZ/PWM_HZ/4` |
| 启动斜坡 | 逐拍上升 | `pwm_and_startup_ramp.v` |

**为什么放在顶层**：段表、航向修正、以后调参都可能把目标速度算大；`nav_speed_limit`
是最后一道硬件闸门，**任何软件/表格错误都不能让轮子超过 60 mm/s**。

改动方式：
- 新增 `src/nav_speed_limit.v`（纯组合钳位 + `clamped` 标志）；
- `task4_navigation_board_top.v` 增加参数 `MAX_WHEEL_SPEED_MM_S=60`，在 `convert_mm_s()`
  之前插入限幅；
- `task4_navigation_single_leg_probe_top.v` 透传该参数（默认 60）。

验证：
- 新增 `sim/tb_nav_speed_limit.v`：0 / ±42 / ±60 直通；61、500、INT32 极值全部钳到 ±60，
  单轮钳位标志正确 —— **7/7 PASS**；
- 全工程回归重跑：RTL 编译、pose/guard/supervisor/event/map、**物理闭环**
  （PASS，停车误差 32.28 mm、航向 0.692°）、板级安全默认（PASS）、三个几何/碰撞脚本；
- `run_sim.ps1` 已把限速测试纳入并检查 PASS 标记。

## 4. 上板怎么做（详见 `FLOOR_TEST_RUNBOOK.md`）

1. 烧**无线版**位流（推荐，车不用拖线）：
   ```powershell
   programmer_cli --device GW5A-25A --run 2 --fsFile <abs>/impl/pnr/task4_navigation_single_leg_probe_wireless.fs --cable "Gowin USB Cable(FT2CH)"
   ```
2. 电机电源先断检查 STBY/led_ready/OLED → 接线 → 架空确认方向 → 急停放行。
3. Pi/PC 一条命令采集+判读：
   ```bash
   python3 tools/t4_floor.py --seconds 60
   ```
   然后放车到 A 点、朝 +Y、按启动键；结束后自动打印 `判定：PASS` 和报告路径。
