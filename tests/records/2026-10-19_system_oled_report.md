# 主工程 IMU OLED 集成测试报告

日期：2026-10-19（北京时间）。设备 GW5A-LV25UG324C2/I1，Gowin IDE 1.9.12，ModelSim SE-64 10.7。

## 集成行为

- 主工程唯一 IMU 驱动的六轴数据接入已验证姿态模块和 OLED；显示 Roll、Pitch、相对 Yaw、初始化/校准/故障状态。
- 生产默认保持 200 Hz 采样、200 帧零偏校准、约 5 Hz 显示。姿态有效且校准结束后才允许运动、点亮就绪灯。
- OLED 接口为 R3/T3、3.3 V；SDA 通过输出数据恒 0 的三态缓冲器实现开漏。CPU/SSPI 普通 IO 选项及 50 MHz 设置已写入主工程保存配置和构建 Tcl。
- 采样超时即使驱动 ready 仍高，OLED 也会在后续帧显示 ERROR；故障锁存后不会因驱动恢复而再次显示正常就绪。电机安全关断不等待显示刷新。
- UART 原事件格式、心跳要求、急停、双轮闭环与 IMU 故障锁存均保留。姿态角仅用于显示。

## 上板交付

打开主工程 `Embodied_RPACS.gprj`；若 IDE 已打开该工程，关闭并重新打开以加载新配置。
下载 `impl/pnr/Embodied_RPACS.fs` 到 SRAM。
按 KEY0 后静止等待校准，就绪灯亮后检查姿态显示；每 100 ms 持续发送二进制 A5，再按 KEY1 检查原 8 秒运行，随后验收急停及心跳超时。
完整步骤见 `tests/docs/SYSTEM_IMU_OLED.md`。本次未代用户下载 FPGA 或操作真实电机。
